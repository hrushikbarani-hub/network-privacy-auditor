What the report can tell you

The blocked share describes query outcomes in the imported file. It does not measure all ads removed, all tracking prevented, or the security of the network. Unknown outcomes stay separate.

Distinct device counts are per date bucket within one import. They cannot be added across days or overlapping files to obtain a network-wide unique count. Separate imports are never merged automatically.

Retention removes old aggregate date buckets on page load, import and settings changes. The app cannot erase the original file on your computer. Clearing site data also removes saved reports.
